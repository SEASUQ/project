# Little Platformer

Учебный платформер на C++ для первого курса. Нужно пройти три уровня,
перепрыгнуть ямы и врагов и дойти до зелёного флага. По дороге можно собирать
монеты. На всю игру даются три жизни.

Код использует структуры, обычные массивы, условия, циклы и функции.
Собственных шаблонов, STL-контейнеров, наследования и игрового движка нет.
Единственная внешняя библиотека — SDL2: она создаёт окно, читает клавиатуру
и рисует прямоугольники. Физика и правила игры написаны отдельно.
Графика и маленький шрифт рисуются программно, поэтому папка с ресурсами не нужна.

## Возможности

- Три уровня с платформами и ямами; сложность постепенно увеличивается.
- Движение, прыжок, сила тяжести и столкновения с платформами.
- Камера, которая следует за игроком.
- Монеты и счётчик собранных монет.
- Патрулирующие враги: прыжок сверху уничтожает врага, касание сбоку отнимает жизнь.
- Главное меню, пауза, экран проигрыша и экран победы.
- Автоматическая пауза при переключении в другое окно.

## Управление

| Клавиша | Действие |
| --- | --- |
| Enter | Начать игру; после победы или поражения начать заново |
| A / D или стрелки влево / вправо | Движение |
| Пробел, W или стрелка вверх | Прыжок |
| P | Пауза / продолжение |
| R | Начать всю игру заново |
| Esc | Выйти |

Прыжок срабатывает при нажатии клавиши, а не при её удержании.
После потери жизни текущий уровень начинается заново: монеты этого уровня
возвращаются на места, монеты уже пройденных уровней сохраняются.
Собирать все монеты для перехода к следующему уровню не обязательно.

## Сборка через CMake

Нужны компилятор с поддержкой C++11, CMake 3.16 или новее и SDL2 2.0.10 или новее
с заголовочными файлами. SDL3 для этого проекта не подходит.

### Linux (Ubuntu / Debian)

```sh
sudo apt update
sudo apt install build-essential cmake libsdl2-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/platformer
```

### macOS

Установить инструменты разработчика и SDL2 через Homebrew:

```sh
xcode-select --install
brew install cmake sdl2
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/platformer
```

Если компоновщик сообщает `tapi error: malformed file` из-за несовместимого
SDK, выбрать установленный SDK из Xcode:

```sh
cmake -S . -B build -DCMAKE_OSX_SYSROOT="$(xcrun --sdk macosx --show-sdk-path)"
```

Если выбранный SDK тоже несовместим, передать путь к совместимому SDK
в `CMAKE_OSX_SYSROOT`. Это настройка инструментов на компьютере, а не игры.

### Windows (Visual Studio)

1. Установить Visual Studio с компонентом «Разработка классических приложений на C++» и CMake.
2. Скачать архив **SDL2-devel для Visual C++** из [релизов SDL2](https://github.com/libsdl-org/SDL/releases?q=release-2&expanded=true) и распаковать его.
3. Выполнить команды, подставив путь к папке `cmake` из архива:

```sh
cmake -S . -B build -A x64 -DSDL2_DIR="C:/libraries/SDL2/cmake"
cmake --build build --config Release
```

Скопировать `SDL2.dll` из папки `lib/x64` архива рядом с
`build/Release/platformer.exe`, затем запустить этот файл.
Для 32-битной сборки архитектура и DLL должны быть 32-битными.

Если CMake не находит SDL2 на любой системе, можно явно указать папку,
содержащую `SDL2Config.cmake` или `sdl2-config.cmake`, через `-DSDL2_DIR=...`.
Подключение библиотеки соответствует [документации SDL2 для CMake](https://wiki.libsdl.org/SDL2/README-cmake).

## Проверка

После сборки:

```sh
ctest --test-dir build -C Release --output-on-failure
```

Проверяются прыжки, отсутствие двойного прыжка, столкновения с полом,
боками и нижней стороной платформ, монеты, жизни, враги, пауза и победа.
Отдельно проверяется, что все ямы на каждом уровне можно перепрыгнуть
при обычных параметрах физики; в этой проверке враги отключены.

Логику можно собрать и проверить без графической библиотеки:

```sh
cmake -S . -B build-logic -DBUILD_GAME=OFF
cmake --build build-logic
ctest --test-dir build-logic --output-on-failure
```

Проверка окна и отрисовки всех экранов с автоматическим завершением:

```sh
./build/platformer --smoke-test
```

На Windows использовать `build/Release/platformer.exe --smoke-test`.
Эта проверка требует графического окружения либо драйвера SDL `dummy`.

## Как устроен проект

Подробный разбор **каждого файла и каждой функции**, порядок работы программы
и распределение модулей: [docs/FILES.md](docs/FILES.md).

| Файл | Назначение |
| --- | --- |
| `CMakeLists.txt` | Сборка игры и проверок |
| `src/main.cpp` | Окно, события клавиатуры и главный цикл |
| `src/game.h` | Константы, структуры и объявления функций |
| `src/game.cpp` | Карта, движение, столкновения, монеты и враги |
| `src/drawing.h` | Объявление функции рисования |
| `src/drawing.cpp` | Рисование игры и надписей |
| `tests/game_tests.cpp` | Проверки игровой логики |
| `.github/workflows/build.yml` | Автоматическая сборка и проверки на GitHub |
| `.gitignore` | Исключение результатов сборки и локальных настроек из Git |
| `README.md` | Описание проекта, управление и запуск |
| `docs/FILES.md` | Подробное объяснение всех файлов и функций |

Карта — массив из 16 строк и 64 столбцов. Размер клетки — 40 пикселей.
Символ `#` обозначает платформу, `.` — пустое место, `o` — монету,
`F` — финиш. Уровни задаются в функции `loadLevel`.

Движение рассчитывается с постоянным шагом 1/120 секунды.
В главном цикле накапливается прошедшее время, а затем выполняется нужное
число шагов физики. Скорость движения не зависит от частоты отрисовки.
Сначала проверяются столкновения по горизонтали, затем по вертикали.
При падении на платформу вертикальная скорость становится нулевой,
и игрок снова может прыгнуть.

Для изменения игры можно поменять расположение платформ и ям в `loadLevel`,
скорость движения и силу прыжка в `updateGame`, а цвета — в `drawing.cpp`.
